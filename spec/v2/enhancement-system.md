# 神女控 V2 — FIFA式合卡强化系统

## 概述

独立于 Evolution 的系统。Evolution 负责形态变化，Enhancement 负责同形态的"+值"强化。

## 强化等级

+0 至 +10

## 材料规则

- 主卡：需要强化的卡牌
- 材料卡：相同 cardFamilyId 或完全相同 cardId 的卡牌
- 材料强化等级越高，成功率越高
- 最多投入多个材料（配置化上限）

## 基础成功率（配置化）

| 强化 | 成功率 |
|:---|:---|
| +0→+1 | 100% |
| +1→+2 | 90% |
| +2→+3 | 75% |
| +3→+4 | 60% |
| +4→+5 | 45% |
| +5→+6 | 30% |
| +6→+7 | 20% |
| +7→+8 | 12% |
| +8→+9 | 7% |
| +9→+10 | 3% |

材料强化等级加成：同级显著提高，低一级中等提高，+0 少量提高。

## 失败规则

- +1~+4 失败：材料消失，主卡不降级
- +5~+7 失败：材料消失，主卡有概率保持/有概率降1级
- +8~+10 失败：材料消失，主卡默认降1级，不永久销毁

## 保护机制

- 强化保护券：失败不降级
- 失败祝福值：每次失败累积，提高下次成功率
- 连续失败保底：连续 N 次失败后下次必定成功
- 成功概率公示：界面显示的概率 = 实际概率
- 强化历史记录
- 关闭赌博式音效/动画的设置

## 属性增幅

强化提供百分比属性加成，边际递减：
- +1: +2%, +2: +4%, +3: +7%, +4: +10%, +5: +14%
- +6: +18%, +7: +23%, +8: +28%, +9: +34%, +10: +40%

（以上为初始平衡值，配置化）

## 界面要求

显示：当前强化等级、目标等级、成功概率、失败结果、消耗卡牌、Gold费用、属性提升预览、是否使用保护材料、保底进度

## 测试要求

使用 seeded RNG 建立至少十万次模拟测试，验证显示概率和实际概率误差 < 0.1%。
