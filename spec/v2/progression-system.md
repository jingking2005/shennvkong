# 神女控 V2 — 成长系统

## A. 等级强化 / Fusion

- 使用其他卡牌或经验材料增加等级
- 最多一次投入多个材料
- 消耗 Gold
- 有普通成功和大成功（1.5x 经验）
- 材料稀有度和等级影响经验值
- 预览升级后属性
- 不允许误吞锁定卡
- 编队中/收藏锁定中的卡必须二次确认

经验曲线：配置化 JSON，建议 `expForLevel = floor(100 * level^1.3)`

满级上限：N:20, R:30, SR:40, UR:50, LR:60（进化后提升）

## B. 技能升级

- 使用 Rare Medal 或技能材料
- 影响：伤害倍率/治疗倍率/Buff数值/触发概率/持续时间/倒计时/使用次数
- 不同技能只允许提升合理字段（配置化）
- 最高等级配置化（建议 10 级）

## C. 进化 / Evolution

- 相同卡牌用于进化形态
- 阶段：0星 → 1星 → 2星 → 3星 → 4星(最终)
- 效果：改变卡图/卡框 + 提高基础属性 + 提高等级上限 + 可能强化技能
- 保留部分材料卡属性（继承率配置化，建议 10%）
- 使用继承材料可增加继承比例
- 确定性系统，不使用失败概率

## D. 融合合成 / Amalgamation

- 指定卡牌组合形成新卡牌
- 配方系统：材料卡A + 材料卡B + 额外材料 + 资源费用 → 结果卡
- 必须能通过 JSON 定义配方

## E. 觉醒 / Awakening

- 最终进化卡使用指定素材觉醒
- 效果：稀有度提升 + 属性上限提升 + 技能变化 + 解锁觉醒爆发 + 等级重置 + 部分成长继承

## F. 重生 / Rebirth

- 觉醒卡的终局成长
- 效果：稀有度再次提高 + 解锁强化技能 + 提高等级上限 + 提高觉醒爆发
- 消耗稀有活动材料

## G. 亲密度 / Friendship

- 卡牌参与战斗/升级/进化获得亲密度
- 等级解锁：语音/故事/角色档案/少量攻防加成/专属背景
- 不能成为核心付费强度来源
