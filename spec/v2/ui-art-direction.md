# 神女控 V2 — UI 与美术方向

## 整体风格

日系幻想 + 神界 + 魔法王国 + 神殿 + 天空岛 + 云层 + 魔法符文 + 金色与宝石质感 + 卡牌收藏展示感

## 背景要求

每个主要页面不得使用纯色空背景。即使真实背景资源未准备好，也必须使用：
- 多层渐变
- 程序化星空/云层
- 魔法阵
- 远景剪影
- 粒子 + 柔光 + 纹理
- 轻微视差

## 主要界面清单

王国主页 / 卡牌图鉴 / 队伍编辑 / 卡牌详情 / 升级 / 进化 / 合卡强化 / 抽卡 / 关卡地图 / 战斗 / 结算

## 稀有度卡框

N / R / SR / UR / LR / G级 / X级 — 每种必须有不同视觉卡框

## 属性视觉识别

PASSION=红/火, COOL=蓝/冰, LIGHT=金/光, DARK=紫/暗, SPECIAL=银/特

## 卡牌详情页必须展示

高清立绘 / 卡名 / 稀有度 / 属性 / 角色定位 / 等级 / 强化等级 / 进化阶段 / ATK / DEF / 士兵值 / 主技能 / 被动 / 亲密度 / 来源 / 锁定状态

## 战斗界面必须展示

五人队伍 / 当前行动方 / 士兵值HP / Buff和Debuff图标 / 技能就绪提示 / 技能剩余次数 / 自定义技能倒计时 / 属性克制提示 / 伤害类型 / 战斗日志 / 回合数 / Boss阶段

## 禁止

- 默认 HTML 按钮直接堆放
- 纯白或纯灰背景
- 无层级卡片
- 卡牌简单矩形碰撞
- 所有技能共用同一动画
- 大量调试文字直接显示给玩家

## 队伍编辑界面必须实时显示

总Cost / 角色定位 / 属性分布 / 可激活羁绊 / 缺少的羁绊条件 / 单体输出能力 / 群体输出能力 / 治疗能力 / 控制能力 / 生存能力
