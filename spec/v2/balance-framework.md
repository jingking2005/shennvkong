# 神女控 V2 — 平衡框架

## 原则

1. 所有数值配置化，不硬编码
2. 使用 seeded RNG，所有随机可测试
3. 建立模拟测试验证概率和平衡
4. 边际递减防止极端碾压

## 伤害平衡目标

- 同级同稀有度卡牌，战斗应在 5-15 回合内结束
- 克制属性应提供明显优势但不是一击必杀
- 坦克应能承受 3-5 次普通攻击
- 奶妈应能恢复坦克 1-2 回合的伤害
- 控制应能改变战斗走向但不是必胜

## 养成平衡目标

- +10 卡不应完全碾压 +0 同卡（差距控制在 40% 以内）
- 觉醒卡不应让未觉醒卡完全无用
- 资源获取速度应让玩家每天有明显进步感
- 抽卡不应是唯一强度来源

## 经济平衡目标

- Gold 日产出 ≈ 日消耗的 80-120%
- Jewels 获取有限但不卡死进度
- 免费玩家应能在合理时间内完成所有内容
- 不存在只产出不消耗的死资源

## 模拟测试要求

- 强化概率：10万次模拟，误差 < 0.1%
- 抽卡保底：1万次模拟，验证保底触发
- 战斗平衡：1000场模拟，验证胜率分布
- 经济循环：30天模拟，验证资源不溢出/不枯竭

## 配置化清单

所有以下数值必须来自 JSON 配置文件：
- 伤害公式常数（DEF_CONSTANT）
- 属性克制倍率
- 暴击基础值
- 经验曲线
- 满级上限
- 强化成功率表
- 强化属性加成表
- 进化属性提升率
- 抽卡概率和保底
- 建筑产出和费用
- 关卡敌人配置
- 状态效果数值
