# 神女控 V2 — 内容与模式

## 垂直切片必须实现

### 1. 剧情关卡
- 三波敌人，最后一波 Boss
- 世界地图路径探索（节点式）
- 节点类型：战斗/宝箱/事件/Boss

### 2. 资源关卡
- 产出 Gold、经验材料和技能材料
- 每日可挑战次数配置化

### 3. Archwitch Boss
- 高血量 Boss
- 强调单体输出、Buff、Debuff、治疗和特攻队伍
- 多阶段（血量阈值触发形态变化）

### 4. 元素试炼
- 每天对应不同属性
- 使用正确属性获得额外效果/奖励

### 5. 图鉴
- 查看卡面、属性、技能、形态和来源
- 收集进度统计
