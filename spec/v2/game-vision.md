# 神女控 V2 — 游戏愿景

## 产品定位

以《神女控》原版的卡牌收集、王国经营、队伍搭配和回合战斗为核心，加入现代化技能体系、职业定位、FIFA Online 3 式同卡强化以及完整抽卡养成循环的**单机可持续卡牌 RPG**。

## 核心体验支柱

1. **收集乐趣** — 3500+ 张真实卡图，稀有度/属性/定位多样
2. **队伍构筑** — 5 位置 + 8 职业 + 羁绊 + Cost 限制
3. **战斗策略** — 手动选目标 + 技能释放时机 + 状态博弈
4. **养成反馈** — 等级/技能/进化/强化/觉醒/重生 六层成长
5. **资源规划** — 8 种资源 + 产出消耗闭环
6. **长期目标** — 王国建设 + 高难内容 + 收集完成度
7. **美术展示** — 高清立绘 + 卡框 + 特效 + 层次化 UI
8. **可持续扩展** — 数据驱动，新卡/新关/新活动无需改代码

## 目标用户

- 怀念《神女控》的老玩家
- 喜欢日系卡牌收集的玩家
- 喜欢队伍构筑和策略战斗的玩家
- 喜欢养成反馈和资源管理的玩家

## 技术约束

- 单机运行，无后端依赖
- Web 技术栈（Phaser 3 + TypeScript + Vite），后续可用 Tauri 打包原生
- 数据驱动，所有配置来自 JSON
- 所有随机逻辑支持 seed（可测试/可回放）
- 本地 localStorage 存档

## 非目标

- 不做网络 PvP（垂直切片阶段）
- 不做真实付费（单机版）
- 不做城市建设模拟（简化为资源产出建筑）
- 不做实时战斗（保持回合制）
