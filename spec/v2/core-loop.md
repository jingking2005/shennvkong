# 神女控 V2 — 核心循环

## 主循环

```
收集卡牌 → 查看卡牌与角色故事 → 培养卡牌 → 同卡强化
→ 进化与觉醒 → 配置五人队伍 → 激活羁绊和属性加成
→ 挑战关卡/Boss/活动 → 获得资源与抽卡货币
→ 建设王国 → 解锁更高难度内容 → 继续收集和养成
```

## 单次会话循环（5-15 分钟）

1. 登录 → 收取王国产出
2. 查看任务/活动 → 选择目标
3. 编队（检查羁绊/Cost/定位）
4. 战斗（手动或自动）
5. 结算 → 获得 Gold/经验/材料/卡牌
6. 养成（升级/强化/进化）
7. 抽卡（如有货币）
8. 返回 1 或退出

## 长期循环（数天-数周）

- 收集全图鉴
- 将主力卡强化至 +10
- 觉醒/重生终极形态
- 通关全部剧情 + 高难 Boss
- 王国建筑全满级
- 亲密度全满解锁故事

## 资源流转

```
战斗/关卡 → Gold + 经验材料 + 技能材料 + 抽卡货币
         → 用于：升级 / 技能升级 / 强化 / 抽卡

王国产出 → Gold + Ether + Iron（被动，定时收取）
         → 用于：建筑升级 / 觉醒材料

抽卡 → 新卡 / 重复卡
     → 重复卡用于：进化 / 强化材料 / 分解为 Medal

活动/Boss → 觉醒材料 / 重生材料 / 限定卡
```

## 反馈节奏

| 时间尺度 | 反馈内容 |
|:---|:---|
| 即时（秒） | 伤害数字、技能特效、暴击闪光 |
| 短期（分钟） | 升级、战斗胜利、获得新卡 |
| 中期（小时） | 进化成功、强化+1、通关新区域 |
| 长期（天） | 觉醒、重生、王国新建筑、图鉴完成 |
