# 神女控 V2 — 王国系统

## 概述

王国是经济和战斗成长的一部分，不是空背景。

## 建筑类型

| 建筑 | 功能 |
|:---|:---|
| Castle | 解锁建筑/区域/等级上限 |
| Farm | 产出 Gold |
| EtherFurnace | 产出 Ether |
| IronWorks | 产出 Iron |
| Barracks | 提高队伍 Cost 上限 |
| Arena | 提高进攻队伍容量 |
| Fort | 提高防守队伍容量 |
| FireRuins | 增加 PASSION 属性效果 |
| IceTower | 增加 COOL 属性效果 |
| ShrineOfLight | 增加 LIGHT 属性效果 |
| PaganHall | 增加 DARK 属性效果 |
| Workshop | 增加同时建造队列 |
| SkillLab | 解锁技能研究 |
| AwakeningLab | 处理觉醒材料 |

## 建筑属性

每个建筑具备：等级、升级费用、升级时间、前置建筑、被动收益、解锁内容、可视化状态、收取资源、升级反馈

## MVP 简化

- 使用缩短后的计时（秒级而非小时级）
- 所有时间配置化
- 建筑可视化使用占位图标 + 等级标签
- 资源收取为点击按钮
